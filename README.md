# Consulta Fertilizantes SIPEAGRO

App para consultar as empresas de fertilizantes, inoculantes e corretivos registradas no SIPEAGRO (MAPA).
Abre em https://mathausmandro.github.io/dadossipeagro/

- Fonte: Portal de Dados Abertos do MAPA (conjunto SIPEAGRO – Fertilizantes)
- Atualização: `tools/atualizar.sh`, agendado no Mac todo dia às 7h (`tools/com.sipeagro.atualizar.plist`)
